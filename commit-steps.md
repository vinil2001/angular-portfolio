# Коміт чистого проєкту

1. Перевірте статус:
```bash
git status
```

2. Додайте всі файли:
```bash
git add .
```

3. Зробіть коміт:
```bash
git commit -m "feat: setup Angular with Tailwind CSS

- Initialize Angular 17 project
- Configure Tailwind CSS v3
- Add basic styling structure
- Ready for portfolio development"
```

4. Перевірте гілку:
```bash
git branch
```

Це буде наша точка відліку перед розробкою портфоліо!
